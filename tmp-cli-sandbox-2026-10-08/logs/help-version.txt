LITESPM VERSION

Print the LiteSPM version and build details.

USAGE
  litespm version
  litespm --version
  litespm -v

WHAT IT DOES
  - Prints the LiteSPM version with the protocol version, operating system,
     architecture and Go toolchain of this binary.
  - It is the pair of numbers to quote in a bug report: the release you run
     and the protocol it speaks to agents and the daemon.

WHAT IT DOES NOT
  - Does not contact the network: it cannot tell you whether an update exists
     (that is `litespm self-update`).
  - Reads and changes nothing on disk.

EXAMPLES
  1. litespm version
  2. litespm --version

EXIT CODES
  0  success, including nothing to do
  1  refused or failed
  2  usage error (unknown flag, missing argument, unknown command)
